# Ashry-Real-Estate

A modern, elegant, and fully responsive landing page designed and developed for **Ashry Real Estate (عشري العقارية)**, with a focus on presenting the company's services and real estate projects through an engaging and user-friendly experience.

The project combines a premium visual identity, clean layouts, smooth animations, and responsive design to create a professional online presence for a real estate brand.

---

## ✨ Features

- **Modern UI/UX:** Clean, elegant, and visually appealing interface tailored to the real estate industry.
- **Fully Responsive:** Optimized for desktops, laptops, tablets, and mobile devices.
- **RTL Support:** Complete right-to-left layout with Arabic typography and content.
- **Hero Section:** Attractive introduction with compelling content and clear call-to-action buttons.
- **About Section:** Introduces the company and its identity.
- **Services Section:** Organized presentation of the company's real estate services.
- **Featured Projects:** Attractive property cards and image showcases.
- **Why Choose Us:** Highlights the company's strengths and values.
- **Contact Section:** User-friendly inquiry form and contact options.
- **Interactive Animations:** Smooth transitions, scroll effects, and engaging hover interactions.
- **Responsive Navigation:** Easy-to-use navigation across different screen sizes.
- **Clean Code:** Organized and maintainable code structure.
- **SEO Friendly:** Semantic HTML and optimized page metadata.

## 🚀 Getting Started

To run the project locally:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Ashry-Real-Estate
```

**3. Open the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
